# Effects of Lifestyle and Economic Factors on Life Expectancy in Europe

## Overview
An analysis of how smoking, alcohol consumption, GDP per capita, literacy rate, graduation rate, and unemployment affect life expectancy across European countries using real clinical data.

## Data Source
European Health For All Database (HFA-DB) - official database containing health indicators across European countries by WHO.

## Key Findings
- GDP per capita and literacy rate showed the strongest positive correlation with life expectancy
- Smoking and alcohol consumption showed significant negative correlations
- Multi-variable analysis revealed that economic and educational factors are stronger predictors of longevity than lifestyle factors alone

## Tools Used
Python, pandas, matplotlib, seaborn, SQL, SQLAlchemy, MySQL

## How to Run
Open project.ipynb in Jupyter Notebook or Google Colab. Note: the original MySQL database connection requires U of C credentials. Replace with your own dataset if rerunning.
